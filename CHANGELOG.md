# Changelog

## 0.2.2 (build 30) – September 2026

First public beta under the name **Slicer Mobile**.

- App is visibly called "Slicer Mobile"; App settings → "Open source & licenses"
  with source link and component list
- Dragging the selected object moves it with any tool active (as in PrusaSlicer);
  before, it only rotated the camera in Simple Mode
- Projects opened via "Open with" load with their profiles; a missing filament
  profile is reported
- Switching a profile asks before dropping changes; system profiles can no
  longer be silently "overwritten"
- Simple Mode: readable values on the cards, date in the app language, preview
  card top right, project notice also in Advanced Mode
- Phone landscape: tool column, slice button and model sheet no longer overlap
- View cube bottom left, back gesture, object bar next to the page
- Preview statistics no longer count "actual speed" clones of the toolpaths twice
- Many translations added (dependency reasons, units, first-run setup, dialogs)
- Buy-me-a-coffee link on the start screen

## 0.2.1 (build 21) – 14 September 2026

- Core with OCCT (STEP import), targetSdk 36
- View cube, wrapping toolbar, 24-bit depth buffer
- Phone layouts, bed sheet, object bar; findings from the Galaxy S23 FE

## 0.2.0 – 0.1.x – July to September 2026

Android-first build-up, then iOS as the reference and Android as its 1:1 twin;
first-run setup, Simple/Advanced Mode, multi-bed, painting, PrusaLink,
remote slicing (WIP), self-test, parity guard.
